# Password Strength Checker

#### Video Demo:  https://www.youtube.com/@khaledmahmoud1923

#### Description:
My final project for CS50 Cybersecurity. A Python tool to evaluate password strength.

**Features:**
- Checks length (8+ chars).
- Verifies numbers, uppercase, lowercase, and symbols.
- Gives instant feedback (Weak/Medium/Strong).

**How to run:**
`python project.py`
